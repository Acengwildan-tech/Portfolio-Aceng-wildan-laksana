// Tentang Saya

Mengembangkan Solusi Software & Hardware

Saya adalah seorang siswa dari SMKN 1 Kawali jurusan Rekayasa Perangkat Lunak (RPL). Memiliki ketertarikan mendalam pada dunia pemrograman web dan otomasi perangkat keras melalui Internet of Things (IoT).

Dalam pembelajaran dan proyek harian, saya terbiasa membangun aplikasi web interaktif menggunakan HTML, CSS, JavaScript, PHP, dan Framework Laravel, serta mengelola basis data MySQL. Selain dunia web, saya aktif mengulik micro-controller Arduino untuk menciptakan sistem perangkat keras berbasis IoT.
